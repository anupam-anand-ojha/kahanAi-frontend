# KahanAI — AI-Powered Storytelling

KahanAI is an AI-powered storytelling platform designed to bring imagination to life. Explore unique worlds, create personalized stories, and discover immersive adventures through an intuitive and engaging interface.

## ✨ Features

- 🌌 **Immersive Worlds** — Explore unique story settings and fictional universes.
- ✍️ **AI Story Generation** — Generate personalized stories using AI.
- 🎭 **Interactive Storytelling** — Experience stories shaped by user choices.
- 📖 **Engaging Reading Experience** — Enjoy stories through a clean, modern interface.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- ESLint
- CSS

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/kahanai-frontend.git
   ```

2. Navigate to the project directory:

   ```bash
   cd kahanai-frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
